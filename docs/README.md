# Docs

Architecture documents and operational guides for the Citrate blockchain.

## Contents

- `CITRATE_DESIGN_MAP.md` -- High-level design map of all subsystems and their relationships
- `CITRATE_TECHNICAL_ARCHITECTURE.md` -- Detailed technical architecture (consensus, execution, storage, networking)
- `guides/` -- Operational guides (installation, deployment, genesis setup, wallet usage)
- `technical/` -- Deep-dive technical documents on specific subsystems

## Usage

These documents are the single source of truth for Citrate architecture. For user-facing documentation, see `docs-portal/`. For sprint planning, see `.sprint/`.

# Docs
Architecture documents and operational guides for the Citrate blockchain.

## Contents

- `CITRATE_DESIGN_MAP.md` -- High-level design map of all subsystems and their relationships (31 contracts, 41 TLA+ specs, compute marketplace, Learning Center)
- `CITRATE_TECHNICAL_ARCHITECTURE.md` -- Detailed technical architecture (consensus, execution, storage, networking, compute, learning)
- `guides/` -- Operational guides (installation, deployment, genesis setup, wallet usage, validator onboarding, GPU provider)
- `technical/` -- Deep-dive technical documents on specific subsystems

## Usage

These documents are the single source of truth for Citrate architecture. For user-facing documentation, see `docs-portal/`. For sprint planning, see `.agentile/sprints/`. For formal verification, see `citrate_v0.01.1/specs/tla/` (41 TLA+ specifications) and `citrate_v0.01.1/specs/.formal/` (verification reports).

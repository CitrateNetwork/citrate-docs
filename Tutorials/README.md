# Tutorials

Tutorial projects and reference dApps demonstrating how to build on the Citrate network.

## Contents

- `ReferenceApp/` -- Reference dApp with ModelNFT (ERC-721 + IPFS CID), Foundry test suite, and deployment scripts
- `ChatVault/` -- Chat-based vault interaction tutorial
- `LoRAForge/` -- LoRA model fine-tuning and on-chain registration tutorial
- `MogSynth/` -- Model orchestration and synthesis tutorial
- `CrossChainDataBridge/` -- Cross-chain inference request protocol + relayer

## Usage

Each subdirectory is a standalone project. See the README within each tutorial for setup instructions. Tutorials assume a running Citrate devnet on http://localhost:8545 (chain ID 40204).

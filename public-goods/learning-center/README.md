# Citrate Learning Center

The Learning Center is Citrate's school-facing product track: a district-operable,
role-gated, privacy-aware interface for classroom operations, student participation,
teacher incentives, and eventually optional on-prem AI tutoring.

This folder is meant to read like the first draft of a future docs site, while
still staying honest about what is verified today.

## Status language used here

- `Verified baseline`: publicly repeatable evidence exists and is anchored to the
  current canonical branch history
- `In progress`: active work exists, but it is not yet the public proof point
- `Target state`: the intended deployment-ready posture once the pilot program closes

## What this folder is trying to do

- explain the product in plain language
- give districts a clean onboarding and security story
- preserve exact technical anchors where they matter
- avoid claiming live readiness where only local proof exists

# Public Goods Documentation

This folder is the repo's public-facing institutional documentation set.

It is written for:

- school districts
- government agencies
- security and procurement reviewers
- future docs-site editors

These documents are intentionally more public and more stable in tone than the
internal `.agentile/` planning material. They still follow a simple truth rule:

- if an exact address, variable, chain ID, command, or artifact matters, code and
  the canonical registers win
- when the finished-state product posture differs from today's verified state, the
  current-state pages say so directly
- we do not use vague security marketing where a concrete control requirement is
  the real issue

## Authority

`public-goods/` is a public documentation layer, not a source of protocol truth.
If any conflict appears, defer in this order:

1. `.agentile/CONFIG.md`
2. deployed-address and source files under `citrate_v0.01.1/`
3. current audited material under `.agentile/audit/` and `.agentile/compliance/`
4. these public-goods documents

## Editorial posture

The goal here is practical public value:

- local control over data and workloads
- platform-neutral deployment
- budget discipline before new spending
- strong security and auditability without ideological grandstanding
- honest distinction between "available now", "under construction", and "target state"

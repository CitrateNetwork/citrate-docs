# State Government

State governments are large enough to justify shared infrastructure, but diverse
enough that one deployment pattern rarely fits every agency.

## Good state-government use cases

- benefits and caseworker knowledge tools
- workforce and unemployment document processing
- DMV or licensing policy search
- statewide training and guidance distribution
- agency-specific private inference environments

## Why Citrate could fit

- states need shared services without total centralization
- statewide procurement often rewards platforms that support many agencies with one base stack
- private-network operation can let agencies share tooling while keeping mission data separated

## Controls that matter most

- agency-by-agency authorization boundaries
- enterprise identity federation
- records retention and audit export
- accessibility and language access
- interoperability with county and municipal partners

## Main blockers

- legacy mainframe and vendor-system integration
- cross-agency governance fights
- inconsistent data classifications
- procurement cycles that reward the largest incumbents by default

## Candidate state-government binaries

- agency gateway node
- state model registry
- caseworker desktop
- secure document automation workstation
- restricted-network AI appliance for one agency at a time

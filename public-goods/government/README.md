# Government Deployment Discovery

This folder is a nonpartisan discovery set for how Citrate could serve local, state,
tribal, federal, and defense-adjacent institutions.

The lens here is intentionally middle-of-the-road:

- pro-local-control
- pro-public-accountability
- pro-open-standards
- pro-budget-discipline
- pro-security and civil liberties at the same time

It is not written to flatter one party, one procurement ideology, or one cloud vendor.

## Core idea

A large amount of public-sector compute sits underused. The opportunity is not to
turn government into a crypto slogan. The opportunity is to let agencies:

- put idle or off-hours compute to work under policy control
- keep sensitive workloads on premises or in restricted enclaves
- move value from compute buyers and institutional workloads back into public systems
  without assuming new taxation is the only funding lever
- collaborate on models and automation with strong provenance, revocation, and audit trails

## What we will not do in these docs

- pretend current repo state equals current certification state
- use the phrase "military grade" as a substitute for actual controls
- assume all agencies can or should move to the same cloud pattern
- assume cross-border model sharing is legally simple

## Policy framing

The product story for government should be:

- vendor-neutral
- platform-neutral
- standards-forward
- privacy-preserving
- auditable
- human-accountable

That is a better frame than left-versus-right arguments, and it is much stronger in
procurement and public oversight settings.
